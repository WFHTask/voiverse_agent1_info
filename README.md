## English

### 🎯 What is AIFocus?

AIFocus is an intelligent information aggregation service designed for AI industry professionals (founders, investors, researchers) who face daily information overload. 

Instead of spending hours jumping between dozens of tabs, AIFocus reads all your information sources — Twitter KOLs, newsletters, research papers, tech media — and surfaces only the most important updates for you.

**We don't add another source. We replace the chaos with a single, personalized stream.**

### ✨ Key Features

- **🎯 Smart Aggregation**: Monitors 100+ AI information sources including:
  - Top AI voices (Lex Fridman, Sam Altman, Andrej Karpathy, etc.)
  - Premier AI media (Hacker News, The Information, TechCrunch, etc.)
  - Research papers, newsletters, and industry reports

- **🤖 AI-Powered Filtering**: Machine learning algorithms identify the most relevant content for you

- **📚 Personalized Learning**: The system learns your preferences over time to deliver increasingly relevant content

- **⏱️ 10-Minute Daily Brief**: Get the day's most important AI news in a digestible format

- **🌍 Bilingual Support**: Automatic language detection (Chinese/English) with manual toggle

### 🚀 Quick Start

**Prerequisites:** Node.js 16+

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Open your browser:**
   ```
   http://localhost:5173
   ```

### 📦 Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist/` directory.

### 🛠️ Tech Stack

- **Frontend**: React 19 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

### 🌐 Deployment

This project is optimized for deployment on:
- GitHub Pages
- Vercel
- Netlify
- Any static hosting service

## 中文

### 🎯 什么是 AIFocus？

AIFocus 是为 AI 行业从业者（创始人、投资人、研究人员）设计的智能信息聚合服务，专门解决每天面对的信息过载问题。

不用再每天花几个小时在几十上百个标签之间跳转，生怕错过最重要的信息。AIFocus 帮你阅读所有信息源 — Twitter KOL、Newsletter、研究论文、科技媒体 — 只把对你最重要的呈现出来。

**我们不是新增一个信息源，而是用一条个性化的信息流取代所有混乱。**

### ✨ 核心功能

- **🎯 智能聚合**: 监控 100+ AI 信息源，包括：
  - 顶级 AI KOL（Lex Fridman、Sam Altman、Andrej Karpathy 等）
  - 主流 AI 媒体（Hacker News、The Information、TechCrunch 等）
  - 研究论文、Newsletter、行业报告

- **🤖 AI 智能过滤**: 机器学习算法识别最相关的内容

- **📚 个性化学习**: 系统学习你的偏好，持续优化推荐内容

- **⏱️ 每日 10 分钟简报**: 将当天最重要的 AI 新闻浓缩为易读格式

- **🌍 双语支持**: 自动语言检测（中/英文），支持手动切换
